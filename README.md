# Struct-Link+

Suite de diseño estructural para Windows bajo NTC 2023, ACI 318-25 y AISC 360-22,
con lectura de modelos de STAAD Pro CONNECT.

## Descarga

El instalador está en la sección **Releases** de este repositorio:
[Struct-Link+ 1.0.0](https://github.com/jemaromx/Enlace-Estructural-Plus/releases/latest).

- Windows 10 u 11 de 64 bits.
- Requiere una licencia de **Struct-Link+**. Una licencia de Struct-Link no sirve
  para Struct-Link+, ni al revés.
- Aviso de privacidad: <https://struct-link.com.mx/privacidad-plus>
- Contacto: contacto@struct-link.com.mx
